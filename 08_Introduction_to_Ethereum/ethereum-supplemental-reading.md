# Ethereum Supplemental Notes

## 1. Node Clients

Ethereum runs on different node client software such as:
- Geth
- Nethermind
- Erigon
- Besu

### Why multiple clients matter:
- Reduces risk of a single point of failure
- If one client has a bug, others keep the network alive
- Improves decentralization and security

### Key idea:
A healthy blockchain requires **client diversity**

---

## 2. Development Tools (Alchemy)

When using Alchemy:
- You do NOT need to run your own node
- Alchemy provides access to multiple node clients behind the scenes

### Benefits:
- One API key gives access to multiple Ethereum APIs
- You can use advanced features without managing infrastructure

## 3. Ethereum History (Very Short Timeline)

- **2013** → Ethereum whitepaper proposed by Vitalik Buterin
- **2014** → Ether initial sale + Yellow Paper
- **2015** → Ethereum mainnet launch
- **2016** → DAO hack → Ethereum & Ethereum Classic split
- **2021** → EIP-1559 introduces gas burning
- **2022** → The Merge (Proof of Stake transition)

---

## 4. Ether as “Ultrasound Money”

- Ether supply can decrease due to gas burning
- Base fee is burned (removed from circulation)
- This can make ETH deflationary under high usage

Key idea:
> Supply reduction + usage = “ultrasound money” narrative

---

## 5. Use Cases of Ethereum

Ethereum is a programmable blockchain used for:

### Ownership
- Digital ownership records
- Asset verification

### Code / Smart Contracts
- Programs that run on-chain
- Transparent and verifiable logic

### Major Applications:
- Decentralized Finance (DeFi)
- NFTs
- DAOs

---

## 6. Key Learning Takeaways

- Ethereum is a **multi-client decentralized system**
- Infrastructure diversity improves security
- Ethereum evolved through major upgrades:
  - EIP-1559 (fee burning)
  - The Merge (PoS transition)
